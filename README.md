📚 Sistema de Gerenciamento de Livraria

Um sistema simples em Python desenvolvido para gerenciamento de acervo de uma livraria via terminal.

🚀 Funcionalidades

Cadastrar Livro: Permite cadastrar um novo livro com ID automático gerado sequencialmente, solicitando o nome do livro, autor e editora.

Consultar Livros:

Consultar todos os livros cadastrados.

Buscar livro por ID específico.

Buscar livros por autor.

Remover Livro: Permite remover um livro cadastrado através de seu ID.

Menu Interativo: Navegação simples e intuitiva via terminal.

🛠️ Tecnologias Utilizadas

Python 3

Dicionários e Listas para estruturação dos dados

Funções modularizadas
